# Ollama Home Chat

A Flutter Android app for chatting with a local Ollama CPU instance running on Ubuntu Server through Big Bear CasaOS.

The app is intended for use only on the home Wi-Fi/network.

## Target setup

- Server: Ubuntu Server
- App platform: Android phone
- Ollama container/app: `ollama-cpu`
- Model: `mistral`
- Default Ollama API port: `11434`

Example local server URL:

```txt
{server-address}:11434
